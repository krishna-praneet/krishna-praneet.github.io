### Practical Considerations for AI Model Deployment
*Supervisor: Prashant Shenoy (UMass) — Jun 2025–Aug 2025*

Demonstrated practical considerations for AI model serving across enterprise edge (PowerEdge R360 + NVIDIA A2s) and adversarial IoT (NVIDIA Jetson Orin NX) conditions for fault-tolerant model inference systems. Quantitatively measured the impact on application latency and accuracy by model loading times, failure detection & reconfiguration times, Mean Time To Recovery (MTTR), and the effect of co-location.

**Topics:** Edge ML, Fault Tolerance, Model Serving, IoT
**Publication:** [MILCOM 2025](https://lass.cs.umass.edu/papers/pdf/milcom2025-practical.pdf)

### Multi-Level Ensemble Learning (MEL)
*Supervisors: Prashant Shenoy (UMass), Suhas Diggavi (UCLA) — Nov 2024–May 2025*

Introduced a novel ML training and architectural framework using a modified multi-objective loss for enhancing fault tolerance in resource-constrained edge AI environments. Preserved up to **95.6%** accuracy using ensembles sized at **40%** of the original model. Attained **25%** lower inference latency through parallelized execution across edge servers, evaluated across vision, audio, and NLP tasks.

**Topics:** Ensemble Learning, Edge AI, Resource-Constrained Inference
**Preprint:** [arXiv:2506.20094](https://arxiv.org/abs/2506.20094)

### Quantum LDPC Decoders
*Supervisor: Stefan Krastanov (UMass) — Sep 2023–May 2024*

Built the first Julia-native low-density parity-check (LDPC) decoders library with **500+ downloads** on JuliaHub, including the first available open-source SOTA iterative decoder. Achieved **30%** improvement in decoding latency compared to existing baselines like python-ldpc, through optimized memory allocations and variable type profiling, and a user-friendly API for benchmarking qLDPC codes with just <10 lines of code.

**Topics:** Quantum Computing, Error Correction, qLDPC Codes, Julia
**Presented at:** APS March Meeting 2024

### Machine Learning for Platinum Nanoclusters
*Supervisor: Satyesh Kumar Yadav (IIT-M) — Aug 2019–May 2020*

Achieved up to **99.5%** accuracy in predictions for over 6 configurations of Platinum nanoclusters in various environments, and a computational speedup of **40%** on an IBM cluster through non-linear ML frameworks for accelerating Ab-initio Molecular Dynamics simulations. Developed a numerical fingerprinting algorithm to capture translation/rotation invariance in 3D and construct feature vectors.

**Topics:** Machine Learning, Molecular Dynamics, Computational Materials Science

### Assisted Defect Recognition with MATLAB
*Supervisors: Jyani Vaddi, Om Prakash (Boeing) — Jun 2018–Jul 2018*

Developed image processing algorithms to identify the volume of shrinkage defects with a mean accuracy of **95%** in the torque arm of aircraft landing gear for Non-Destructive Evaluation. Analyzed raw DICOM images using a combination of mean and Canny Gaussian filters with DFT, and documented an approach for defect segmentation using BPHF and difference of Gaussians, followed by image dilation and erosion.

**Topics:** Image Processing, Non-Destructive Evaluation, MATLAB
